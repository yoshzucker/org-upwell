#+title: org-upwell
#+options: toc:2 num:nil

Files rising to the heading that is being lived.

org-foresight answers *when* a thing fits on the day. org-convect takes
purpose at the top of the ladder and carries it down as far as areas
(H2); the climb back is a reduction -- purpose written again from what
the lower rungs did. This package is the other vertical. It happens at
the day's feet (H1): the files and URLs work is done with rise to the
heading that is being lived. It does not climb the ladder. It supplies
the surface convect and foresight already stand on.

A user heading -- a project in ~project.org~, a task in ~journal.org~, a
meeting calsync wrote -- has a *domain*. Expanding the domain brings back the
Org entry and the files and URLs that claim it. Those files are not listed
under the heading; they point up at its id. upwell.org is storage, not work.

Capture happens *outside* Emacs. A resident watcher records the frontmost
Office document and, when it can, the browser URL, without a hotkey and
without Emacs being focused. Attribution is the intersection of those traces
with CLOCK intervals, including clocks filled in afterwards from the agenda
(org-foresight's ~C~).

* Install (Emacs)

#+begin_src emacs-lisp
(use-package org-upwell
  :load-path "~/Developer/org-upwell"
  :after org
  :config
  ;; Your own open policy, if you have one: it decides which extensions
  ;; go to the OS and which are read inside Emacs.  Unset, files go to
  ;; the OS default application.
  (setq org-upwell-open-function #'my/open-file)
  (org-upwell-mode 1))
#+end_src

Straight users, keep the ~script/~ directory:

#+begin_src emacs-lisp
:straight (org-upwell :host github :repo "yoshzucker/org-upwell"
                      :files ("*.el" ("script" "script/*")))
#+end_src

~org-upwell-mode~ registers org-protocol, the clock hooks (including advice
on ~org-foresight--file-clocked~, so agenda ~C~ attributes traces in the
filled interval), drop handlers, and a quiet sync timer. It does *not* start
the watcher. The watcher is a process of its own.

* Install (the watcher)

The watcher must be a login item, not an Emacs subprocess. On macOS a
privacy prompt spawned by Emacs is attributed to Emacs, which has no
Automation usage string -- the same hole org-calsync hit with Calendar.app.
On Windows, a watcher that dies with Emacs stops catching the hour after
the frame is closed.

Use the AutoHotkey watcher on Windows, the osascript watcher on macOS.
The PowerShell watcher is a fallback for a machine without AutoHotkey;
it is not the one to install.

** Windows (production)

Do not add this to ~remap-windows-keys.ahk~. A separate Startup shortcut
points at ~script/org-upwell-watch.ahk~ in this package (not a copy), so
~git pull~ then a restart is what picks up a new version.

Once:

: powershell -NoProfile -ExecutionPolicy Bypass -File script\install-startup.ps1

The same shortcut is also registered by ~bootstrap.ps1~ (~Setup-StartupShortcuts~).
Log off or restart to start it. Emacs does not have to be running.

** macOS (development / test)

Once:

: bash ~/Developer/org-upwell/script/install-launchagent.macos

That writes ~~/Library/LaunchAgents/org.upwell.watch.plist~ with this
machine's paths, then ~bootstrap~s the job. Re-run after moving the
package. The first Excel / Safari / Chrome / Edge / Finder capture will
ask for Automation permission -- grant it to this job, not to Emacs.

For a one-off test session only (not how it should run day to day):

: M-x org-upwell-watch-start

* Commands

| Command | What it does |
|---|---|
| ~org-upwell-expand~ | Expand the heading at point / the agenda row / the running clock. Opens files. If the bench is already showing, switches it to this heading. Neither the bench nor an agenda loses its window |
| ~org-upwell-expand-clock~ | Expand whatever is being clocked (emacsclient-friendly) |
| ~org-upwell-pin~ | Catch a file or URL. Clock or heading at point → confirmed claim; else unclaimed |
| ~org-upwell-create~ | New xlsx/pptx/…, claimed, no save-location prompt |
| ~org-upwell-open-named~ | Completing-read over the store |
| ~org-upwell-sync~ | Intersect traces with clocks (the timer does this quietly) |
| ~org-upwell-bench~ | Listing of the domain, drop target. A strip cut out of one window -- the one you did *not* call it from -- the way the agenda splits |
| ~org-upwell-follow-mode~ | Keep the bench in step with the Org heading at point |
| ~org-upwell-demo-mode~ | Point the store and the agenda at generated data (like org-foresight-demo-mode) |

Agenda ~F~ (follow mode), with ~org-upwell-mode~ on, also updates the bench from the agenda row. It does not open files.

emacsclient, from AHK or FlowLauncher, to expand the current clock:

: emacsclient -e "(org-upwell-expand-clock)"

org-protocol (bookmarklet in ~script/org-upwell-bookmarklet.txt~):

: org-protocol://upwell?url=…&title=…
: org-protocol://upwell?expand=ORG-ID

* How attribution works

Two clocks, not one.

| What | When | Who |
|---|---|---|
| A *trace* (path/URL + unix time) | every 15s, only if the front document changed; also new files in Downloads | the watcher, Emacs need not be running |
| A *provisional claim* | Emacs intersects traces with CLOCK intervals: a 60s timer while Emacs is up, immediately on clock-out, immediately after foresight ~C~ / ~H~ | Emacs |
| A *confirmed claim* | clock-out or ~C~ / ~H~ review (Enter keeps, ~n~ rejects, ~r~ reassigns). An explicit pin/drop is confirmed at once | you |
| A *rejection* | the same review's ~n~ / ~r~. Written down, because the intersection runs again a minute later and would otherwise propose the same file | you |

The watcher does not know Org. If Emacs is closed, traces pile up and wait.
Nothing is guessed when there is no clock: that file becomes an
unclaimed item, a row on the foresight board, not a wrong project.

An answer you gave -- kept or rejected -- is never overwritten by a later
sample. A rejected file is not on the heading and is unclaimed again; it
just is not offered for that heading a second time.

* Where the files live

| What | Where | Why |
|---|---|---|
| Identity (upwell.org) | ~org-directory~ (~/Documents/memex/~) | it is Org, next to journal and projects |
| Traces (JSONL) | ~~/.local/share/org-upwell/~ | the watcher is not Emacs; this path exists without ~.emacs.d~ |

~/.emacs.d/~ (and no-littering's ~var/~) is for files Emacs writes. The
watcher starts at login, often before Emacs, and must not need it.

* What this is not

- Not org-attach. Screenshots belong to the note; xlsx belongs to Excel.
- Not a 1:1 heading-to-folder map. A folder is one appearance.
- Not a document database. ScanSnap archives stay on disk until pinned.
- Not a replacement for FlowLauncher.
